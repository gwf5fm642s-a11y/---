Задание 3. Реализация Middleware и обработки ошибок
1. Реализация журналирования HTTP-запросов
Создан регистр сведений ЖурналHTTPЗапросов, предназначенный для хранения информации об обработанных HTTP-запросах.
В регистре сохраняются:
дата и время начала запроса;
HTTP-метод;
путь запроса;
HTTP-код ответа;
длительность выполнения в миллисекундах;
время окончания запроса.

Создан общий модуль ЛогированиеHTTP, содержащий процедуру ЗаписатьЗапрос(). Процедура сохраняет сведения о запросе в регистр и формирует запись в журнале регистрации.
Журналирование проверено на запросах к API, в том числе на тестовых ошибочных запросах /api/error и /api/async-error. Записи об обоих запросах успешно появились в регистре.

2. Реализация сжатия HTTP-ответов
Для сжатия ответов на стороне Apache использованы модули mod_deflate и mod_filter.
В конфигурацию Apache добавлены правила сжатия для HTML, CSS, JavaScript, JSON и XML.
Работа сжатия проверена через инструменты разработчика браузера. В заголовках ответа присутствует:
Content-Encoding: gzip

3. Реализация ограничения количества запросов
Создан регистр сведений ЛимитHTTPЗапросов, в котором хранится количество запросов за минуту для IP-адреса.
Создан общий модуль ОграничениеHTTP с функцией ПроверитьЛимит(). Функция проверяет количество запросов за текущую минуту. Предусмотрен лимит 100 запросов в минуту.
Для ответа API добавлены заголовки:
X-RateLimit-Limit: 100 — установленный лимит;
X-RateLimit-Remaining: 99 — количество оставшихся запросов в демонстрационной проверке.
Наличие заголовков проверено в браузере.
